# 背面整圈黑边修复

旧自动算法使用 contour_depth，逐深度取原图参考，因此四边共有的暗圈也被保留。新 contour_depth_lift 从每张背面原图稳定金属框取得明度，只提升低于该目标的轮廓层，叠加平滑切向校正。处理保持 Lab a/b（量化误差除外）、原纹理、尺寸、alpha、贴纸与非背面金属区域。

源图生成四边/四角独立样点，再要求中位数至少恢复至金属参考差值的 55%，第 10 百分位至少恢复 50%；这属于本拍摄规范的数值门禁，不能代替颜色与纹理视觉验收。旧暗圈须被新门禁拒绝。八区在深浅背景各生成 1×/4×证据，另查纸尾和天线端点。

隔离回归（几何基线仅用于定位光照问题，正式自动流程仍从原图重新处理）：

```bash
python -m scripts.regression_rear_perimeter --geometry /本机过程/geometry-records/staged/SKU_01 --old /旧六面图片/SKU_01/back.png --output /新建回归目录
```

回归重新生成本图材料与纸面蒙版，先冻结效果目标，再计算并验证：旧图被拒绝，新图通过，alpha/纸面/区外无变化。修复范围包含背面金属圈及其内侧同材质光照过渡带，范围外与旧成品逐像素一致。光照工具同时保留 contour_depth 供确需保留真实材质层次的其他面使用，不改变前面策略。

本次效果与完整原图流程验证保存在项目 outputs/rear-perimeter-lift-20261023；业务照片不提交 Git。


## 按钮凸出与光照坐标（2026-10-23）

SKU_07 背面按钮旁出现类似保护框的断续颜色。实际 protected_mask 只有纸面；问题是直接用含按钮凸出的 alpha 估计轮廓法向与深度，把按钮形状带进了邻近金属的照明场。

现在从本图长边采样，以分位二次曲线估计连续机身边缘，作为 `contour_alpha_mask` 光照坐标。原 alpha、实际可编辑范围与材料域保持原样；按钮仍参与处理。坐标 mask 只用于确定取样方向和可靠金属样本，不是保护蒙版，不裁切按钮或修改成品几何。沿每个源图检测到的凸出区新增同材质照明连续性检查，新增校正的逐行阶跃不得超过 1.25 L。贴纸仍是唯一像素保护。

本次 SKU_07 原图端到端验证及 Pro Max 光照回归、11 套几何坐标兼容检查记录在项目 `outputs/rear-button-continuity-20261023`。局部外背面材料与其他五面分别核对；模型 UV 全面视觉验收仍独立进行。

## 光照域硬边界与色域裁切（2026-10-23）

按钮修复后，SKU_07 背面内侧仍有锯齿状色阶：rear_perimeter 和相邻金属域的校正量直接硬切。Pro Max 高亮处还有逐像素色域裁切引起的校正碎点。旧按钮纵向检查不能覆盖横向分区边界。
