# 顶面本体标定与独立运行

适用范围：当前命名、方向、分辨率和拍摄姿态符合 iPhone 17 铝材质检采集规范的六面原图。程序不调用 LLM、Agent 或生图服务；BiRefNet_dynamic 是可由程序直接调用的分割模型，并不等于 Agent 依赖。输入六张原图即可调用 `phone-texture auto`。最终用户验收不参与算法执行。

## 必须满足的结果

- top 只保留真实顶边框；整块相机台阶、镜头圆柱、镜片及凸起轮廓均排除。只去镜头圆柱仍不合格。
- 相机不参与顶面上缘、角度、厚度、尺寸标定。每张重新测量自己的原图；运行不读历史 SKU 坐标或验收蒙版。
- 两端圆角、边框内部纹理和真实损伤保留；仅修改透明度并做一次刚性旋转，不画出原图没有的轮廓。
- 原图证据不足时失败，错误码以 `TOP_` 开头；无 Agent 补点重试、无阈值放宽、无静默保留摄像头。

## 程序实现与拒绝条件

`phone_texture/top_frame.py` 从主连通体两端露出的圆角测量上下边界。拟合点位于本采集规范的外侧 0.6%–3.5% 宽度范围，内部交错留出 1/3 样点检查拟合；这些是统一采集规范，不是逐 SKU 标定。拟合残差 p95 ≤1.5 px，留出误差 p95 ≤2 px，两端厚度差 ≤4 px，刚性旋转后两条边剩余倾斜 ≤0.15°。角点形状/尺度及原图 RGB 梯度也必须符合规范。中央两半的原图交界各需至少 80% 支持。该有限模型不声称识别任意型号、透视、遮挡或拍摄方式；不支持时返回失败。

相机上边界的广泛支持不能替代机身证据。源图本体内部像素逐像素验证，外部相机区域 alpha 必须为零，旋转及透明精裁后再次检查。运行报告包含采样点、残差、RGB 支持率、变换检查、源图/输出哈希和 `runtime_agent_required: false`。代码通过不等于未知照片均正确，实际样本回归另存。

`auto` 和 `standardize` 的 top 共用标定。旧 `geometry-guides` 的 top 必须提供原图并通过同样的相机排除和机身保留检查；`reviewed` 不能豁免。低层仅有 matte 的 `extract_frame_strip(face='top')` 拒绝处理，使用带 `source_image` 的 `normalize_frame_strip`。已裁 PNG 的 `deskew` 仅处理方向，不能证明摄像头已去除；它不替代原图标定。

## 自动运行与验收的边界

`auto` 内部的六面处理、蒙版、光照参数、背面天线基准和数值检查都是软件逻辑，开发可以直接运行 CLI 或调用 `phone_texture.automatic.run`。正常执行无需补充人工材料，也不会进入对话等待。失败写入结果文件，整批不完整时不发布完整批次候选。

输出仍是交给用户验收的六面候选；程序不伪造视觉签收或当前 Blender UV 证据。历史 `start/run/approve-geometry` 是显式资料与签收流程，不能把它的 Agent 填表步骤混进无 Agent 自动路径。不锈钢高光生成流程另有依赖，不包含在本次铝材自动能力中。

本次修正的正确性回归与性能压测分开。修正后先检查十套顶面、保留其他面，再由用户确认是否启动新压测；不得复用旧版速度作为本版结果。
