# 六面工坊接入记录：铝边框强去阴影明亮模式

日期：2026-11-04。当前验证对象：标准版 iPhone 17，sku1 银紫色铝边框实拍。用户认可顶底面较强提亮效果，并要求左右面做成类似效果；明确用图片颜色对比控制，不进入 Blender 对照 UV。用户还要求记录方法，准备更新六面工坊。

## 已交付的处理口径

这是经用户选定的强去阴影风格，不是恢复物理固有色。仅校正金属明度：保留源 Lab a/b、细纹与可见磨损；保留一些局部材质起伏。前后面不变。天线塑料、深色结构槽、镜头/相机控制键玻璃不能套金属的明亮目标。本次左右金属按钮面和 SIM 金属面参与同材质明度统一，轮廓、位置、孔槽仍不变。

位置校准和光照校正是不同阶段。使用已通过几何、天线和按钮校准的 PNG 作不可变快照，不重新抠图、不缩放、不旋转、不做生成填补。每轮参数试算都回到同一基线，不在上一个试算结果上叠加提亮。完整自动流水线更适合冻结原几何材料标记、复用既定结构映射；不能把几何校准后的旧坐标直接套回原图。

## 顶底两端：从暗端到邻近金属

此前参数 strength=0.72、横向低频尺度约宽度的 12%、最大 L 偏移 35，保留了强端部阴影。改用同库 `lighting.engine('aluminum').process_view`，保留支持度门禁 0.008；没有改低失败阈值。

1. 原几何基线分出主金属、纸面、开孔和天线条；贴纸按真实纸边保护。使用已认可处理图中邻近金属的 L 中位数作目标，RGB 改色未授权，所以只使用 L，a/b 保留各源像素。
2. 该样本主金属域 `strength=[0.98,0,0]`，`sigma=[3,max(6,0.006*width)]`（数组按 y,x），`max_lab_shift=[65,0,0]`，`correction_smooth=1.5`，外轮廓 `feather=0`。这组参数不是通用机型参数。
3. 从原几何基线重新求校正候选；bottom 继续使用同一源哈希绑定的充电口映射，保持接口位置。金属蒙版沿同一个映射换算。
4. 与既有结构成品在 Lab 中比较，只增加正的 L 差值。距两端小于长轴 14% 全强度；14%–24% 用 smoothstep 平滑衰减至零，内段保持原图。透明区隐藏 RGB 不变。
5. 原四个暗端 L 中位数约 55，处理后约 92.2–94.1，与邻近亮金属差约 1.8–3.5 L*。检查的是同材质 ROI，不把开孔、塑料或边框投影混进统计。

历史可复现程序与全部输入哈希：`outputs/sku1-six-view-20261104/end-lighting/run.py`、`checks.json`、`pixel-checks.json`。该记录位于项目根目录的 outputs 中，不在仓库交付图片内。

## 左右两面：以认可的顶底面作同材质参考

可复用实现：`phone_texture/bright_aluminum.py`，函数 `refine_sides(source, work)`。输入为同一台手机已经对齐的六张 PNG，且 top/bottom 是本次认可的亮度参考；work 必须新建。返回待视觉复核候选和报告，不直接覆盖输入，也不自动发布。

- 在 top/bottom 两端分别采样：长轴 1%–7%、93%–99%，短轴 25%–75%，alpha>240，得到四个 L 中位数，再取中位数作为共同金属目标。本样本为 93.069 L*；不得把这个数硬编码给其他颜色/批次。生产接入必须将参考框与金属材料蒙版取交集，并校验参考无贴纸、塑料、孔洞和高光污染；当前取样范围只验证了本样本。
- 在当前已对齐的左右 PNG 中重新绑定材料和结构：主金属、金属按钮面分别校正；天线、暗沟、相机控制玻璃各自保留材料归属。纸面保护仍为 sticker_only，非金属不参与金属目标不等于把邻近金属冻结。
- 主金属和金属按钮面 strength=[0.98,0,0]，sigma=[max(6,0.006*height),3]，最大 L 偏移 65，correction_smooth=1.5，feather=0。向统一参考校正缓变阴影，只增加正的明度差；保留已有更亮区域，避免为了统一而压暗高光。
- 基于当前结构快照一次合成，保留源 a/b，8 位量化存在细小色差；本次 a/b 变化的 P99 均小于 0.4。逐像素 alpha、非金属域、纸面与隐藏 RGB 不变。

## 必须保留的检查与产品接入边界

- 校验输入和参考 SHA256、尺寸和全部 alpha。改动只能在本次金属域；非金属材料、透明像素、贴纸以及其他四面逐像素或文件哈希相同。不能重新采样左右图片。
- 对上端、中段、下端各自统计中位数和 P10。当前样本各 ROI 与共同目标差需≤5 L*，实际不到1；不能用整面平均掩盖端部暗块。新颜色应根据参考差独立确定阈值，不用本例的绝对亮度当默认。
- 原尺寸看整体；4倍看四个端部、四颗按钮/卡槽、相机控制键周边、天线与金属交界。检查纹理、暗沟、磨损、晕圈、色块和抗锯齿边。程序数值通过与用户视觉认可分开记录。
- 六面工坊建议新增显式的“强去阴影／明亮金属”选项，保留原风格模式；不默认覆盖其他颜色或材质。不锈钢、玻璃、塑料不能共用此目标。
