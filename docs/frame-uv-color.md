# 固定模型边框 UV 接缝校色

自动入口现在要求选择 `iphone17pro` 或 `iphone17promax`，网页提供型号下拉框，CLI 使用 `--model`。不得按图片分辨率或背板长宽比猜型号：现有样本比例相近，且裁切、纸尾会改变比例。每批同型号，不改并发滑块和文件夹选择器。

六面原图 → 抠图/材料光照 → 本机背面结构对齐 → 实际 UV 接缝颜色配对 → 完整六面输出。

## 依据与范围

`phone_texture/seam_profiles/` 两份 JSON 从当前 3D 看外观程序实际加载的 GLB 提取，包含模型 SHA-256、四条跨材质接缝的完整世界坐标弧长、两侧 UV、内向方向和单位比例。UV 采用图片像素中心坐标；图片尺寸变化时保持归一化 UV 不变，同时转换内向法线。顶底面采样位于图片内部约 4–5% 宽度处，不能用 PNG 外缘代替。

这里验证左右边框与顶底边框的四角颜色衔接，不代表任意其他 UV 模型的兼容证明。模型 UV、节点映射或几何发生变化时应重新提取并复核配置，不复用旧坐标。固定模型轮廓/按钮/镜头的完整语义配准仍是独立要求。

## 方法

从本 SKU 已完成基本光照和结构对齐的基线读取颜色。原图识别的 `main_surface` 金属域通过同一结构映射传递；不从输出差异反推编辑范围。只在四角接缝局部施加平滑 Lab 偏移及跨缝梯度匹配，保留源细节残差，不改变模型、UV、像素坐标、尺寸或 alpha。前后图字节复制，贴纸、天线、按钮不纳入角部金属校正。此处用户已授权消除跨面的颜色差，允许局部匹配 L/a/b，不在其他材料上统一涂色。

处理真实 UV 内收，还需覆盖采样足迹。边外延续 18 px 支持滤波；两次有界残差迭代始终累加到原始浮点校正场，不反复重采样/模糊成品。过渡宽度为当前固定模型的 0.20 世界单位，实际像素宽度随图片转换，不假称此单位是毫米。

每条缝 192 个等弧长样本，联合可编辑覆盖须 ≥98%，低频 ΔE76 第95百分位须 ≤2。任何一条失败均阻断完整输出；不能只统计容易处理的区域。验证报告含前后误差、覆盖、源文件及模型指纹。单一指标不能替代四角无光照及 PBR 近景检查。
