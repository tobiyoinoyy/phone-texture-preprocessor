# 已认可的加强提亮候选

`phone-texture auto` 的独立候选默认采用 `accepted-shadow-lift-v1`。它以用户已认可的 Pro SKU14、SKU34 两组实际效果为目标，**不代表其他 SKU 已获得视觉验收**。`--lighting-profile baseline` 保留此前光照提案以便对照复现。

该候选建立在 NS11 的源图识别、无纸面像素保护、投影边界分离及明确的原位待审输出之上。不包含未验收的充电口三维变形。所有材料参考仍从本组、本面的未调光几何源图取样，不采用其他设备颜色，不把成图模糊后覆盖原纹理。

## 阴影提亮的实际变化

- 在完整、不透明的当前材料片区内寻找稳定较亮取色块：金属及硬件参考局部均值的第85百分位，天线使用其自身第75百分位，并按局部方差惩罚不稳定亮点。每次保存真实参考框与源图亮度。
- 正面由仅保留原深度暗轨的 `contour_depth` 改为 `contour_depth_lift`。正面屏幕与背面镜片不会跟随金属处理。
- 顶底面沿长度方向的拟合尺度由约宽度12%缩为4.5%，正常方向4.5像素，减少亮杆身对暗端帽修正量的稀释；颜色域安全限制跟随拟合校正场。
- 左右金属拟合尺度为 `[max(36, h*.025), max(4, w*.035)]`。金属与硬件强度0.98，天线0.90；仅允许调整 L，单材料最大幅度60 L。保留既有色域、材质边界和源特征连续性约束。
- 纸面有自己的源图拟合，最大6 L、强度0.8。它可以改变亮度，不冻结纸面或纸外矩形，不重绘文字及二维码；不需要判明纸条末端才能继续。原有 `label_component_N` 并入同一独立纸面材质，防止重复拆分造成误拒绝。

`supported_field` 的0.008支持门槛未降低。没有最近邻、常量或中位数空洞补值。光照必须保持尺寸、所有 alpha、透明像素隐藏 RGB 及有效区外像素。天线位置在光照前冻结，结构重映射另存阶段，按钮与端帽的锁定检查保持有效。

## 预警和失败的含义

新目标中，仅 `Perimeter/Regional/Local effect failed` 这类源图相对的外观目标预警可以继续后续阶段。原失败值与检查不通过状态保留，结果为 `full_stages_effect_warning_needs_review`，**不计入所有程序检查完成的数量**。这避免了因为局部亮度目标不符合已认可外观而退回未调光图。源哈希、alpha、拟合支持、结构映射、材料覆盖及接缝连续性等失败仍按原规则处理。

天线证据不足仍可按默认 `preserve-source` 输出原位置待审候选；此类结果不推断不可见端点，不声称已经结构对齐或完成所有面调光。逐面记录包含真实选择的阶段以及任何调光回退。已认可的 Pro14 全阶段强制实验和默认原位待审流程不同：认可不自动使其源端点证据变充分。

接缝数值检查使用随工具附带的固定模型 UV 配置。用户当前模型 UV 由用户处理；没有该场景的证据时不称实际三维接缝合格。用户最终外观验收、源图证据、程序完成和文件生成分别记录。

## 验证和使用

候选必须先通过同源样本、不同机型/颜色与负例回归，并检查源图、透明轮廓、天线、完整按钮和接缝。用户认可的两组通过原几何检查点精确重放12张最终PNG，全部字节一致；新原照批量结果另行统计，不拿检查点重放当成新抠图。

候选未替换正在运行的 S1；不自动加载 Blender、不改模型、不覆盖历史照片或旧成图。运行时依赖与此前相同，必须使用 BiRefNet_dynamic。查看 `phone-texture auto --help` 以及逐组过程报告后再决定是否采用新候选。
