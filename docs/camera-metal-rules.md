# iPhone 17 系列实拍贴图通用规则

适用范围为六面工坊已支持的 iPhone 17、17 Pro、17 Pro Max。调光按当前照片的材质和实测边界工作。新增机型时须验证镜头布局、凸台材料范围和对应拍摄样本。

## 背面调光

| 会话中确认的问题 | 正式处理规则 | 核验 |
| --- | --- | --- |
| 镜片和凸台相互影响，镜头下沿出现第二条暗线 | 在调光前的彩色照片上以灰度提取镜片、金属框内外缘。三摄常规定位失败时可用局部增强灰度提名，再回到原片复测。源图和调光图的框面交集才参加整圈均光。 | 每颗镜头单独记录可信角度。按同一位置比对原片和成品的径向亮暗，检测新增的第二个暗谷。 |
| 镜头下方提亮后仍有灰蓝色带 | 排除硬件，在同一凸台、同一方向的稳定表面采集 Lab 参考，同时修正投影的明度和色偏。真实接缝保留。 | 参考区不足或跨越材质时跳过该方向。分别核对亮度差、色差和镜片内部像素。 |
| 金属框上出现亮斑、暗斑 | 同一台的镜头金属框共用一个从本机测得的金属色目标。原图提供纹理，两条边缘平滑过渡。 | 逐个金属框比较第 90 与第 10 百分位的明度差。 |
| 深色机的凸台小瑕疵、闪光灯外围经处理更黑 | 先排除硬件、眩光和接缝，用正常同材质金属估计两种尺度的平滑光照增量，再从原图重建整个受影响区域。局部暗点、亮点、接缝本身及其上下表面一起接受该光照。单独识别闪光灯外圈，周边按同方向正常表面调光。 | 对比原照片局部反差。无法测定闪光灯时略过其周边专项处理。 |
| 橙色凸台的颗粒和块状暗斑同时被放大 | 按本机金属颜色启用分尺度处理，分别校正中尺度暗斑和细颗粒，避开硬件及其过渡区。 | 检查原尺寸纹理、较大暗斑和金属色。 |
| 标准版双摄容易借到玻璃背板的颜色 | 实测两个镜头及其金属框，将取样限定在双摄胶囊内有依据的区域。Pro 系列单独测量三摄台阶及同平面金属。 | 镜头数、可用方向、实际处理像素均进入报告。 |

运行记录位于背面调光的 `camera_metal` 项。灰度是定位与测光的中间量，成品保留原机色彩。网页和 CLI 使用同一调光引擎。历史照明参数按原记录重放；降级调光应单独计数。

## 已有六面规则

| 环节 | 已确认口径 | 入口 |
| --- | --- | --- |
| 正背精裁 | 清除夹具及上下整行透明留白，分别测顶部左右留白。按机型配准镜头位置。 | `auto_geometry`、`back_geometry`、`back_lens`、`iphone17_back_finish` |
| 顶面倾斜或屏幕突出 | 从机身金属上沿及机型厚宽比推算下沿位置，再用当张照片下沿交叉验证，避开镜头、屏幕突起及支架。 | `top_frame`、`top_body_template` |
| 左右方向、按钮及天线 | 拍摄规范一致时用摄像头凸起端辅助辨别左右。按键证据弱可沿用实拍位置并记录提示。天线以同台对应背面边缘为准。 | `side_camera_position`、`iphone17_structure`、`auto_structure` |
| USB-C | 原图和成品独立寻找连续稳定的灰度档位，按机型孔位布局验证孔、螺丝及完整口沿。 | `bottom_rectify`、`iphone17_port` |
| 四边接缝和边缘偏灰 | 同机相邻金属取色，端部色相、彩度沿边过渡，沿用已验收的 A1.5。四角接缝分别复测。 | `frame_seams`、`frame_end_color`、`frame_end_saturation` |
| 交付 | 效果提示与处理阶段分开记录。六面完整才进入正式导出目录。飞书回填覆盖抠图列，保留拍摄原图；行高属于回填设置。 | 六面导出与飞书回填 |

## 已认可的共用光照场如何复测

保留同一实拍坐标的四张图：调光前原图、旧调光、已认可样图和本次输出。用 `scripts/regression_camera_shared_field.py` 传入四张图、接缝点与闪光灯位置。工具独立读取凸台下沿上方、接缝、接缝下方及闪光灯外围的局部反差，并检查灯芯及透明度。要求成品与原图的差距进入已认可样图的范围（允许 0.75 L* 的测量差）。位置参数只用于复测；正式调光由当前照片推导处理范围。
