# 质检图优化for不锈钢边框

目标是局部去高光，不再全图重建材质或重新打光。最终图以原图像素为底，只允许已登记高光蒙版内的 RGB 改变；蒙版外每个 RGBA 像素、整幅 alpha、宽高、方向和像素位置必须与源图完全相同。贴纸、孔洞、按键、天线、真实磨损等受保护内容始终保留原像素。

高光覆盖区需要改变像素才能去除高光，其中被过曝遮住的信息不可凭空恢复。只能将补全结果称为邻近材质推断，不能宣称这些区域也保持原像素或恢复了真实隐藏瑕疵。

## 输入与执行范围

- 接收手机原图或六面目录，只处理用户授权的组。先测试一组、通过后继续的要求是批量执行边界，不提前处理其他组。
- 保留源文件，不覆盖旧成品。测试要求不写回用户目录时，在独立工作区测试目录保存图片和记录。
- 型号与颜色已知就沿用；仅做有充分源图依据的局部高光修复时，不因缺少型号重复追问。不能根据新机参考重涂原有颜色。只有局部材质确实无法辨认时，才补充核实对应型号信息。
- 修改技能本身不授权生图；用户明确要求带样本测试时才执行该测试。

## 快速执行

默认快速流程：检查源图并建立高光蒙版后，仅对含确认高光的面各生成一次；没有确认高光的面直接逐字节复制原文件。有可用并发时最多三路独立处理，主执行者汇总记录，避免不同工作者写入同一文件。

只对明显几何错误、缺失或不可用的高光补片针对性重试该面最多一次，每次从原图生成。轻微差异只记录，不自动扩展蒙版或转为整面精修。裁切/蒙版/合成错误先修确定性后处理，不用重绘碰运气。记录实际调用起止、生成次数、重试原因和总耗时，不保证固定分钟数。

## 工具与模型

使用内置 image_gen 编辑高光补片，先读 imagegen 技能；本地编辑目标先用 view_image 查看，再传 referenced_image_paths。工具没有区域 mask 参数时，通过提示词说明修复位置，最终范围由本地二值蒙版强制约束，不能把提示词当作像素保留保证。

沿用用户已经授权的工具。若用户指定 Image 2.5，分别记录 requested_model 与 actual_model；当前工具无法显示或选择后端型号时记 unverified，不通过提示词伪称已选择某个版本。会话已经接受内置工具时不重复询问。不得为速度擅自换成 API、其他模型或额外付费入口。

局部材质补全使用图像编辑工具；本地程序负责候选对齐、局部明暗与纹理匹配、限定范围合成、原像素保留与检验，不做全局降曝光、锐化、磨皮或调色。匹配可参考同一原图的干净材质纹理，但必须记录参考范围，禁止把供体中的天线、孔洞、边框或划痕搬进高光区。

## 1. 识别并锁定可编辑区域

逐张查看原图，记录尺寸、alpha、方向和主要结构。区分过曝灯条/镜面反光与贴纸、闪光灯、孔洞、天线、倒角、裸露金属及真实划痕。不能全图按亮度阈值把亮色内容当作高光。用户已明确判定的高光按其指示处理。

在生成之前为每面保存与源图等大的**二值高光蒙版**（0/255）：白色区域是唯一允许改变的位置。矩形或多边形只覆盖确认的高光及必要的极小接缝空间，不能包含整块暗反射区、整面金属或大面积正常纹理。阈值可辅助选取已目视确认区域，不能代替分类。禁止先查看模型差异再把差异区域补标为高光来通过检查。

返修时先回看原图核对是否漏选灯条光晕、亮端和高光边缘。确属原有反光的遗漏可以重新登记蒙版，并保留前后蒙版及源图依据；不能因为候选不自然就扩大正常材质区。蒙版检查应包括半透明像素中的反光颜色，不能把所有半透明像素自动当作不可编辑的实体结构。

另存源坐标的保护蒙版，覆盖完整贴纸及其抗锯齿纸边，并覆盖与高光相邻或重叠的真实结构、可见瑕疵。保护蒙版优先于高光蒙版。对可能是磨损或倒角的亮线保守保留、记录原因，不为消除所有亮色而擦除实物证据。

无法确认有可修复高光时使用全黑蒙版，直接保留原图。可给用户查看蒙版或前后对照，但不要求每面重复确认。参考 [references/work-order.md](references/work-order.md) 记录边界及依据。

## 2. 仅生成高光补片候选

使用 [references/edit-prompt.md](references/edit-prompt.md)。每次一张主原图，明确高光位置与旁边原有颜色、纹理、明暗。要求仅将高光接续为原有材质，不调整整图照明，不统一颜色，不锐化划痕，不美化或补漆，也不抬亮邻近暗区。

候选可以整面生成以提供上下文，也可以使用带充分上下文的局部裁图；候选本身不是成品。必须记录候选像素到源图的对应关系。保持结构、方向、比例；不一次生成六宫格、不混用不同设备。没有高光的面不调用生成工具。

## 3. 合成并验证原像素

读取 [references/postprocess.md](references/postprocess.md)，使用 [scripts/composite_natural_highlights.py](scripts/composite_natural_highlights.py)。以完整原图为输出底图，只把匹配原图明暗与纹理后的局部 RGB 写入允许区域。只缩放/裁切候选，绝不重采样整幅源图或整幅最终成品。

有效允许区域 = 高光蒙版 ∩ 源图 alpha>0 的像素 ∩ 非保护区域。保留全部源 alpha 数值，因此尺寸、轮廓位置和透明度不变；确认高光覆盖到半透明边缘时只修复其中 RGB，不能为保留反光颜色而留下白色月牙。alpha=0 的隐藏 RGB 以及高光范围外全部 RGBA 均保持原样。

先匹配同一表面的低频明暗和纹理尺度，再进行局部边界衔接。候选中的云斑、横带和错误尺度纹理不能因出自 AI 就保留为“细节”。原图相邻未受高光影响的材质是色调和纹理统计依据；不能直接粘贴亮度不一致的矩形补片，也不能把高光内部过曝的白色混回补片来冒充自然过渡。

对细长灯条，按连通区方向优先沿短轴匹配两侧同一材质的原像素，避免把上下或左右的金属亮边扩散成长条内部的新亮斑。不能只凭边界数值变小就判定效果更好。

为每块高光选取同一原图中已目视确认没有结构的干净材质参考区。低频底色和二维细纹分别处理：不能把一行/列原纹理拉伸成整块条纹，也不能只匹配纹理强度而忽略方向、尺度和接续位置。参考区里的结构边与候选云斑都应排除，不能当作需要保留的纹理。参考坐标与蒙版只适用于当前图片，其他组应重新核对。

所有衔接计算和变化仍限制在有效允许区域内部，保护区域与外部权重严格为0。旧的向内羽化只用于明确选择的兼容模式；不能模糊蒙版后向外扩散。禁止全图色彩匹配或接缝处理影响区域外像素。固定边界仍有高光或真实结构冲突时，记录具体边缘问题，不能偷偷扩大蒙版掩盖。

从保存后的 PNG 重新读取并硬校验：
- 尺寸与源图完全相同；所有 alpha 值完全相同。
- 高光蒙版外 RGBA 不同像素数为 0；保护区域 RGBA 不同像素数为 0。
- 实际变化像素全部属于有效允许区域；原文件哈希不变。
- 全黑蒙版时输出文件与原文件逐字节相同。

失败时不交付为合格结果。旧的 `finalize_restore.py` 仅保留兼容历史工作流，不得以其整面替换输出作为本模式成品。

## 4. 查看效果与交付

按原尺寸与约3倍局部放大检查每处补片，确认明暗、纹理方向及密度与邻近表面连贯，尤其检查矩形暗块、雾状云斑、横竖条纹、假天线和白色细圈。仍能明显认出补片时继续修正，不能仅因为“比上一版好”就标记通过。必要时比较区域边界两侧的颜色跳变，但数值改善不能替代目视检查。像素校验只能证明改动范围受限，不证明遮住的纹理真实。分别报告机械结果、视觉结果和未处理的不确定亮区。

每组成品目录只放 front.png、back.png、left.png、right.png、top.png、bottom.png（仅交付实际存在的面）。预览、说明、原始候选、蒙版、提示词和检查报告存放在该目录之外的记录目录。不要在用户禁止写入的目录创建测试、缓存或说明文件。

最终给出结果或对照预览、位置及简短验证结论，说明哪些面进行了局部修复、哪些面原样保留。用户尚未确认试验通过时，后续批量组保持未开始。
